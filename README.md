# Trang chúc mừng 20/10

## Đưa lên GitHub Pages
1. Vào github.com → New repository → đặt tên (ví dụ `chuc-20-10`) → chọn Public → Create.
2. Bấm "uploading an existing file", kéo thả TOÀN BỘ file trong thư mục này (index.html, music.mp3, thư mục images) → Commit changes.
3. Settings → Pages → Source: "Deploy from a branch" → Branch `main`, thư mục `/ (root)` → Save.
4. Đợi 1–2 phút, link sẽ là https://TEN-GITHUB.github.io/TEN-REPO/ . Tạo mã QR từ link này.

## Sửa nội dung
Mở index.html trên GitHub → biểu tượng bút chì → sửa khối DATA ở đầu file → Commit. Sau khoảng 1 phút trang cập nhật.
Ảnh: tải vào thư mục images/, rồi ghi tên file vào photos.
Nhạc: thay file music.mp3 (giữ nguyên tên).
